# Security policy

Please [report security vulnerabilities privately on GitHub](https://github.com/heyrtl/doorman/security/advisories/new). For ordinary bugs or feature requests, use [GitHub Issues](https://github.com/heyrtl/doorman/issues/new/choose).

Doorman provides security fixes for the latest published release. Include the package version, framework, deployment setup, affected behavior, and steps a maintainer can use to reproduce the issue. Remove credentials and private page content from examples and logs.
